The games' source code lives in private repositories. This repo exists only so anyone
can file a report without needing source access.

## File a report

Click **[Issues → New Issue](../../issues/new/choose)** and pick a template:

- 🐛 **Bug report** — something is broken
- ✨ **Feature request** — something you would like to see

The first question on both forms is **which game**. That answer becomes a
`game: …` label automatically, so each title's reports stay filterable:
[Pyrewarden](../../issues?q=is%3Aissue+label%3A%22game%3A+Pyrewarden%22) ·
[The Concord Quarter](../../issues?q=is%3Aissue+label%3A%22game%3A+The+Concord+Quarter%22) ·
[Wardenmark](../../issues?q=is%3Aissue+label%3A%22game%3A+Wardenmark%22) ·
[The Hushed Ledger](../../issues?q=is%3Aissue+label%3A%22game%3A+The+Hushed+Ledger%22)

## Before filing

1. **Search existing issues** — yours may already be there; a 👍 reaction counts for
   more than a duplicate.
2. **Include the game version** — every Morass game prints it in small text in a
   corner of the main menu.
3. **Include reproduction steps** — what you did, what you expected, what happened.

## The older trackers

Each game used to have its own repo (`pyrewarden-issues`, `wardenmark-issues`,
`the-concord-quarter-issues`). None had ever received an issue, so nothing needed
moving. They are kept and left **open**, with their forms removed and every route off
them pointing here, so that a bookmark or a search result lands on a redirect rather
than on an archived repo's disabled *New Issue* button.
